
**Java Collections** - Interfaces, not classes
- List
- Set
- Map

Java collections can contain only references (not primitives)

**There are different subclasses (subtypes) of each of these, too:**
- ArrayList
- HashMap

**Array**
- Fixed Length
- Fixed Datatype (including primitives)
- Not actually a Java Collection, not a class
- Does implement Object methods

ArrayList is a type of list, not an array.


**Generics**
- Allows you to create classes, interfaces, methods, that work with any type of object while ensuring type safety at compile time.

- class that implements the List interface
